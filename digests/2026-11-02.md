## Aaron Levie

*CEO, Box*

**If your AI output could have been produced before AI existed, you're not pushing AI hard enough.**

Levie argues we've crossed a threshold: AI should now produce outcomes that are qualitatively different, not just faster versions of old outputs. A prototype should have features you couldn't have designed before; research should consume every fact across every dimension; a business process should learn from all past failures in a way no human could. Intelligence is still "jagged," but on enough dimensions that combining AI with human strengths yields fundamentally different results. The litmus test is simple: if you could have done it without AI, you're underutilizing it.

Levie 认为我们已经越过一个门槛：AI 现在应该产出质的不同、而非仅仅是更快的旧产出。原型应该有你以前设计不出的功能；研究应该穷尽每个维度的每个事实；业务流程应该以人类无法企及的方式从所有历史失败中学习。智能仍然"参差不齐"，但在足够多的维度上，AI 与人类优势结合会产生根本不同的结果。试金石很简单：如果不用 AI 也能做到，那你就没有充分利用 AI。

## Latent Space — Using Agents for Long-Horizon Financial Work — Aman Singh, Arca

*Latent Space*

**Arca's agents prompt people more than people prompt agents — the inversion that defines an AI-native firm vs. a firm with AI tools.**

Aman Singh leads the AI platform team at Arca, an AI-native wealth management firm that raised $64M. Arca is not a SaaS company — it is the financial firm itself, which lets it standardize how work happens so agents can participate in predictable ways. AI replaces all the work around the advisor, not the advisor: clients never interface with AI directly, but experience a level of service impossible before, delivered through human empathy. The core architecture is a model-agnostic harness built internally. Claude is the primary model today, but they've cycled through Gemini and OpenAI, guided solely by internal benchmarks — external benchmarks misled them on Luna, which proved too slow and costly. Tasks are tiered: tax analysis gets Opus/Sonnet/heavy GPT; background activity gets lighter models. Advisors never see these decisions.

For a 10-day process like liquidating assets for a tax bill, agents handle all analysis and surface a plan for human review, but cannot execute trades or move money — strict guardrails enforce human-in-the-loop for any money movement or client communication. Safety is deterministic at the edges: every database write gets LLM verification, inbound data is scanned for prompt injection, outbound data is checked for PII exfiltration via a consensus of small models. Auditability is by default — every action by agent or human produces a changelog, which also powers the agentic loop.

Long-horizon memory works through persistence per client plus a "dreaming process" that reflects on the state of the world and updates memory systems. When a fresh signal arrives (e.g., a phone call mid-process), a new agent wakes up, ramps on the client's current state via memory, and contributes to the ongoing workflow. Decision models (Jev) catch models confidently using outdated financial facts like 2025 tax brackets, nudging them toward verified knowledge.

Feedback loops are first-class: every staff edit or cancellation requires a "why" and becomes an eval. Traces couple with feedback, and a nightly meta-agent suggests harness improvements — though a human engineer stays in the loop for prompt changes, because "agents will make really nasty prompt changes if you leave them to it; every little fix becomes the whole prompt."

Arca is deliberately not taking a dependency on managed agent products from labs. Singh's reasoning: "Owning your intelligence gives you the ability to impact the business. If you hand off the intelligence to another provider, you lose some of that control." Anthropic entering financial services is validating for the industry, but Singh draws a sharp distinction: a services firm with AI tools requires users to prompt agents; an AI-native firm has agents that prompt people, running proactively 24/7.

Aman Singh 领导 Arca 的 AI 平台团队。Arca 是一家融资 6400 万美元的 AI 原生财富管理公司，不是 SaaS 公司——它本身就是金融机构，因此可以标准化工作流程，让 agent 以可预测的方式参与。AI 替换的是 advisor 周围的所有工作，而非 advisor 本身：客户从不直接接触 AI，但体验到前所未有的服务水平，通过人类的共情来传递。核心架构是自建的模型无关 harness，Claude 是当前主力模型，但内部 benchmark 是唯一决策依据——外部 benchmark 在 Luna 上误导了他们，实际太慢太贵。任务分层：税务分析用 Opus/Sonnet/重型 GPT，后台活动用轻量模型，advisor 完全无感。

10 天流程中（如为税单变现资产），agent 完成所有分析并呈现方案供人审核，但不能执行交易或动钱——严格 guardrail 在任何资金操作或客户沟通上强制 human-in-the-loop。安全在边界上做确定性检查：每次数据库写入经 LLM 验证，入站数据扫描 prompt injection，出站数据用小模型共识检测 PII 泄露。审计是默认能力——agent 和人的每个操作都产生 changelog，同时驱动 agentic loop。

长周期记忆通过 per-client 持久化加"做梦过程"实现——反思世界状态并更新记忆系统。新信号到达时（如流程中的电话），新 agent 唤醒后通过记忆快速理解客户当前状态并加入工作流。决策模型（Jev）拦截模型自信使用过时金融数据（如 2025 税率）的行为，引导其使用已验证知识。

反馈闭环是一等公民：每次人工编辑或取消必须给理由并成为 eval。trace 与反馈配对，夜间 meta-agent 建议 harness 改进——但 prompt 变更仍需工程师审核，因为"agent 会做出很糟糕的 prompt 修改，每个小修复都会变成整个 prompt。"

Arca 刻意不依赖实验室的托管 agent 产品。Singh 的理由："拥有你的智能才能影响业务。把智能交给别的 provider，你就失去了那种控制。" Anthropic 进入金融服务对行业是验证，但 Singh 划清界限：有 AI 工具的服务公司需要用户去 prompt agent；AI 原生公司的 agent 主动找人，7×24 小时运行。
