## Claude Blog: Claude in Chrome is generally available

**Claude in Chrome 正式全面可用，新增自主行动能力和多层 prompt injection 防御，攻击成功率降至 0%。**

Claude in Chrome 现在对所有付费计划开放。核心变化：Claude 可以在浏览器中自主执行操作（无需逐步审批），通过安全分类器在执行前验证每个操作是否安全且符合用户意图。这让 Claude 能访问内部仪表板、遗留系统和供应商门户等没有 API 的工具，使用用户已有的登录态。

在 prompt injection 防御方面，Anthropic 报告了强力评估结果：在专业红队测试的更强攻击下，Opus 4.5 被攻击成功率 17.6%，Opus 5 仅 3.8%。加上 probes 和安全分类器后，Sonnet 5 和 Opus 5 的攻击成功率为 0%，Fable 5 仅 0.3%（且均为低严重性场景）。防御体系包括三层：模型训练对抗攻击库、probes 扫描网页内容、分类器验证待执行操作。
