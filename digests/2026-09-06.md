### Claude in Chrome is generally available

Claude in Chrome is now generally available on paid plans, featuring autonomous actions validated by a safety classifier to prevent prompt injection attacks. The post details robust defenses against malicious instructions hidden in web content, using probes to screen web results and classifiers to verify actions against user intent. Evaluations show a 0% attack success rate against recent models like Opus 5 and Sonnet 5 when using these safeguards.

Claude in Chrome 现已在付费计划中全面上线，其特色是由安全分类器验证的自主操作，以防止提示注入攻击。文章详细介绍了针对隐藏在网络内容中的恶意指令的强大防御措施，使用探测器筛选 Web 结果，并使用分类器根据用户意图验证操作。评估显示，在使用这些安全措施的情况下，针对 Opus 5 和 Sonnet 5 等最新模型的攻击成功率为 0%。

### Claude gets its own browser in Cowork

Claude now has a built-in browser in the desktop app's Cowork feature, separate from the user's own browser to enhance privacy and security. This allows Claude to perform web tasks like filling forms or pulling data from dashboards without needing extensions or accessing the user's personal tabs and passwords. It uses the same prompt injection safeguards as the Chrome extension and is rolling out to Pro, Max, and Team plans.

Claude 现在在桌面应用的 Cowork 功能中拥有内置浏览器，它与用户自己的浏览器分离，以增强隐私和安全性。这使得 Claude 可以执行填写表单或从仪表板提取数据等 Web 任务，而无需扩展程序或访问用户的个人标签页和密码。它使用与 Chrome 扩展相同的提示注入防护措施，并正在向 Pro、Max 和 Team 计划推出。
