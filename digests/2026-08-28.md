## Claude Blog: Claude in Chrome is generally available

**Claude in Chrome is now generally available for all paid plans, featuring autonomous actions and robust defenses against prompt injection.**

Users can now grant Claude permission to take actions in the browser autonomously, such as navigating pages and filling forms, without approving every single step. A safety classifier validates each action before execution to ensure it aligns with user intent. Anthropic reports that with their latest safeguards—including probes that screen web content and classifiers that verify actions—Claude Opus 5 and Sonnet 5 achieved a 0% success rate against prompt injection attacks in their evaluations, while Fable 5 saw only a 0.3% success rate in low-severity scenarios.

Claude in Chrome 现已面向所有付费计划普遍可用，具备自主操作能力和针对 prompt injection 的强大防御功能。用户现在可以授予 Claude 在浏览器中自主执行操作的权限（如导航页面和填写表单），而无需批准每一步。安全分类器会在执行前验证每个操作，以确保其符合用户意图。Anthropic 报告称，借助其最新的安全措施——包括筛选网页内容的探针和验证操作的分类器——Claude Opus 5 和 Sonnet 5 在评估中实现了 0% 的 prompt injection 攻击成功率，而 Fable 5 仅在低严重性场景中出现了 0.3% 的成功率。

## Claude Blog: Claude gets its own browser in Cowork

**Claude Cowork now features a built-in browser in the desktop app, allowing agents to handle web tasks independently of your personal browser.**

This new built-in browser opens in a side panel when a task requires web access, enabling Claude to read pages, click links, and fill out forms. Crucially, this browser is separate from your own; Claude does not see your tabs, bookmarks, or passwords unless you explicitly choose to share logins site-by-site. This feature is distinct from the "Claude in Chrome" extension, which is designed for working on pages you already have open. The built-in browser is rolling out to Pro, Max, and Team plans and includes the same prompt injection safeguards as the Chrome extension.

Claude Cowork 现在在桌面应用中内置了浏览器，允许 agent 独立于你的个人浏览器处理网络任务。当任务需要访问网络时，这个新的内置浏览器会在侧边栏中打开，使 Claude 能够阅读页面、点击链接和填写表单。关键是，这个浏览器与你自己的浏览器是分开的；除非你明确选择逐站共享登录信息，否则 Claude 不会看到你的标签页、书签或密码。此功能不同于“Claude in Chrome”扩展程序，后者旨在处理你已打开的页面。内置浏览器正面向 Pro、Max 和 Team 计划推出，并包含与 Chrome 扩展程序相同的 prompt injection 防护措施。
