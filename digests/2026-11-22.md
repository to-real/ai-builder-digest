## Aaron Levie

*CEO, Box*

**Agents have crossed the threshold from executing instructions to solving problems you can't define yourself.**

A year ago, you needed to tell agents precisely how to design and develop your product idea, or failure was nearly guaranteed. Now, the agent can likely come up with a better implementation than you'd have thought of, because it connects dots across a far greater solution space than any person can hold. This will reshape every domain of knowledge work where no single person can hold all relevant industry knowledge: finance, legal, life sciences, cyber. The shift: stop telling agents how, start giving them goals and enough freedom to pursue them.

一年前你必须精确告诉 agent 怎么设计和开发你的产品想法，否则几乎注定失败。现在 agent 很可能想出比你更好的实现方案，因为它能在远超个人认知的解决方案空间中建立连接。这将重塑所有知识工作领域，只要那个领域没有人能掌握所有相关行业知识：金融、法律、生命科学、网络安全。转变在于：不再告诉 agent 怎么做，而是给目标，给它足够的自由去追求最优解。

## Latent Space — Scaling Linear's GTM to $100M ARR — Cristina Cordova, COO

*Latent Space*

**Over 50% of issues on Linear are now created by agents, and the company is betting its entire future on agent orchestration rather than manual issue tracking.**

Cristina Cordova, COO of Linear (previously Stripe for 7.5 years, then Notion), walked through how Linear scaled from a startup-favorite PLG tool to an enterprise contender. The most striking data point: since launching their MCP server in 2025, over 50% of issues on Linear are now created by agents. In 18 months, half of all work creation shifted to an entirely new paradigm.

Cordova pushed back against the idea that tools should become bare databases with MCP servers: "I actually think that a lot of companies right now are feeling like it's gonna be okay to just be a database and have an MCP server and give all of their data away to agents... and I don't think that's going to be a great business model ultimately." The key metric Linear watches: both MCP usage and in-app usage rising together, proving the product serves agents and humans simultaneously.

When CEO Karri wrote "issue tracking is dead," the team was fully aligned. The insight: manual work tracking is dead, not the issue itself. Linear is repositioning as a "product development system" where agents handle triage, labeling, and workflow orchestration. Features like Triage Intelligence automatically route incoming bugs and feature requests without human intervention.

On GTM: Cordova killed the enterprise goal three weeks after joining (one salesperson can't do enterprise). She focused on growth-stage companies first, launched enterprise only in 2025. Linear has no SDRs (AEs write their own outbound), doesn't outsource support, and has moved to usage-based pricing for AI features while keeping seat-based pricing for the core product. AI agent chat is free; coding sessions pass through API costs transparently with a small markup.

Cristina Cordova，Linear COO（此前在 Stripe 工作 7.5 年，之后在 Notion），讲述了 Linear 如何从创业公司最爱的 PLG 工具成长为企业级竞争者。最引人注目的数据：自 2025 年推出 MCP server 以来，Linear 上超过 50% 的 issue 由 agent 创建。18 个月内，一半的工作创建方式已完全转变。

Cordova 反对了工具应变成纯数据库加 MCP server 的想法："我认为现在很多公司觉得只要做一个数据库、挂个 MCP server、把数据交给 agent 就行了……但我不认为这最终会是一个好的商业模式。" Linear 关注的关键指标：MCP 使用量和应用内使用量同时上升，证明产品同时服务好 agent 和人类。

CEO Karri 写"issue tracking is dead"时，团队完全一致。核心洞察：手动工作追踪已死，而非 issue 本身。Linear 正重新定位为"产品开发系统"，由 agent 处理分流、标记和工作流编排。Triage Intelligence 等功能可自动路由进来的 bug 和功能请求，无需人工干预。

关于 GTM：Cordova 入职三周就砍掉了企业目标（一个销售做不了企业）。她先聚焦成长期公司，2025 年才启动企业销售。Linear 没有 SDR（AE 自己写外联邮件），不外包客服，AI 功能转向 usage-based 定价，核心产品保持按席位定价。Agent 聊天免费；编码会话透明传递 API 成本加少量加价。
