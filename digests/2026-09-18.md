## Claude Blog: Claude Cowork and chat are now one Claude

Anthropic is merging Claude Cowork and chat into a single interface to simplify the user experience. Users no longer need to decide where a task belongs; Claude now intelligently routes between quick answers and deep agentic work based on the prompt. Additionally, Claude Docs, Claude Slides, and Claude Design are now integrated directly into conversations, allowing users to draft documents, build presentations, and create visual designs without switching tabs or apps. All three new creative tools are in beta on paid plans, and the rollout is starting with Pro and Max plans.

Anthropic 正在将 Claude Cowork 和 Chat 合并为单一界面以简化用户体验。用户不再需要决定任务属于哪里；Claude 现在会根据 prompt 智能在快速回答和深度 agent 工作之间进行路由。此外，Claude Docs、Claude Slides 和 Claude Design 现已直接集成到对话中，允许用户无需切换标签页或应用即可起草文档、构建演示文稿和创建视觉设计。这三个新的创意工具在付费计划中处于 beta 阶段，并首先向 Pro 和 Max 计划推出。
