## Anthropic Engineering: How we contain Claude across products

**Anthropic uses three distinct isolation patterns—ephemeral containers, human-in-the-loop sandboxes, and local VMs—to cap the "blast radius" of agentic failures.**

The article details how Anthropic secures its agentic products (claude.ai, Claude Code, Claude Cowork) by matching the containment strategy to the user's technical expertise. For Claude Code, they initially relied on human approval but found "approval fatigue" led to 93% auto-approval rates, so they moved to OS-level sandboxes. For Claude Cowork, which targets non-technical users, they use full VM isolation because users cannot be expected to evaluate bash commands. Key lessons include treating project config loading as an inbound internet request and realizing that custom-built proxies are often the weakest link in the security chain.

文章详细介绍了 Anthropic 如何通过匹配用户的技术能力来保护其 agent 产品。对于 Claude Code，他们最初依赖人工批准，但发现“批准疲劳”导致 93% 的自动批准率，因此转向了操作系统级沙箱。对于面向非技术用户的 Claude Cowork，他们使用完整的 VM 隔离，因为不能指望用户评估 bash 命令。关键教训包括：将项目配置加载视为来自互联网的入站请求，并意识到自定义代理通常是安全链中最薄弱的一环。

## Anthropic Engineering: An update on recent Claude Code quality reports

**Anthropic traced recent degradation reports to three specific changes: a reasoning effort default swap, a caching optimization bug, and a verbosity system prompt.**

The postmortem reveals that changing the default reasoning effort from "high" to "medium" to reduce latency made the model feel less intelligent, prompting a reversal. A bug in a caching optimization designed to clear old thinking after an hour of idleness instead cleared it on every turn, causing Claude to appear forgetful and repetitive. Finally, a system prompt instruction to limit text length hurt coding quality. All issues have been resolved, and usage limits are being reset for subscribers.

事后分析显示，为了降低延迟而将默认推理努力从“高”改为“中”，导致模型显得不够智能，这一更改已被撤回。一个旨在闲置一小时后清除旧思考的缓存优化出现 bug，导致它在每一轮都清除思考，使 Claude 看起来健忘且重复。最后，一条限制文本长度的系统提示指令损害了编码质量。所有问题已解决，订阅用户的 usage limits 正在重置。

## Anthropic Engineering: Scaling Managed Agents: Decoupling the brain from the hands

**Managed Agents virtualizes the session, harness, and sandbox into separate interfaces to allow components to fail or be replaced independently.**

By decoupling the "brain" (Claude and harness) from the "hands" (sandboxes and tools), Anthropic moved from a fragile "pets" architecture to a resilient "cattle" architecture. This separation reduced Time-To-First-Token (TTFT) by 60% (p50) and over 90% (p95) because containers are only provisioned when needed. It also improved security by ensuring credentials are never reachable from the sandbox where generated code runs, using patterns like bundling auth with resources or storing tokens in a secure vault accessed via a proxy.

通过将“大脑”与“双手”解耦，Anthropic 从脆弱的“宠物”架构转向了具有韧性的“牲畜”架构。这种分离将 Time-To-First-Token (TTFT) 降低了 60% (p50) 和 90% 以上 (p95)，因为容器仅在需要时才配置。它还通过确保凭据绝不可达运行生成代码的沙箱来提高安全性，使用了将 auth 与资源捆绑或通过代理访问存储在安全保险库中的令牌等模式。

## Claude Blog: Claude Code now supports artifacts

**Artifacts turn Claude Code's work into live, shareable web pages—like PR walkthroughs or incident dashboards—that update in real-time.**

This new feature captures the full context of a session, including codebase, connectors, and conversation, to build visual pages that anyone in the organization can view. Artifacts solve the collaboration problem of "walking the team through what the agent found" by providing a shared, live view that updates as the session progresses. They are private by default and managed with org-level toggles and retention policies.

这一新功能捕获会话的全部上下文（包括代码库、连接器和对话），以构建组织中任何人都可以查看的可视化页面。Artifacts 通过提供共享的实时视图解决了“向团队解释 agent 发现了什么”的协作问题，该视图会随着会话的进展而更新。它们默认为私有，并通过组织级切换和保留策略进行管理。
