## The MAD Podcast — What Happens When Billions of AI Agents Hit Your Database? (Andy Pavlo)

*The MAD Podcast with Matt Turck*

**Databases don't need reinventing for agents — they need the same guardrails we've had for decades, but actually enforced.**

Andy Pavlo, the Carnegie Mellon database professor who taught a generation of engineers (and, indirectly, the AI models trained on his open-source course materials), recently joined ClickHouse to found ClickHouse Labs. His core argument: every month someone loses a production database because an agent deleted something, and the controls to prevent this already exist. "You wouldn't have a new toddler and not put up the guardrail so they don't fall down the stairs." Agents are like sophisticated toddlers — set permissions, use branching for sandboxes, and don't give them the same password as the whole company.

The vector database moat was always thin: it's just an index, and within a year every major DB vendor had one. For agent memory, "everything's a database" — whether JSON files or Postgres, the input to agents is human-readable text either way, but a DB system gives you safety guarantees a file system can't. LLMs now recommend Postgres by default for OLTP; two database companies have asked Pavlo how to get their system recommended first by agents, which he calls "basically SEO." On text-to-SQL, off-the-shelf tools hit ~60% accuracy; one large bank invested years and millions in a rich semantic layer to reach 99.5%. AI can now build entire database systems — over 60% of open-source DB commits come from agents. On self-driving databases, LLMs get you 85% of auto-tuning quality in 15 minutes versus hours for trained ML models. Graph databases remain a niche; Pavlo has a standing bet they won't surpass relational by 2030. GPU databases are getting NVIDIA's backing but the economics are unproven.

Andy Pavlo 是卡内基梅隆大学的数据库教授，教出了一代工程师（也间接教出了基于他开源课程材料训练的 AI 模型），最近加入 ClickHouse 创立 ClickHouse Labs。他的核心论点：每个月都有人因为 agent 删东西而丢掉生产数据库，而防止这种情况的控制机制早就存在。"你不会让一个刚会走路的小孩在没有护栏的楼梯旁边玩。"Agent 就像有能力的幼儿——设好权限、用分支做沙箱、别把全公司的密码都给它。

向量数据库的护城河一直很薄：它只是一个索引，一年内所有主流数据库厂商都有了。对于 agent 记忆，"一切都是数据库"——不管是 JSON 文件还是 Postgres，输入给 agent 的都是人类可读文本，但数据库系统能提供文件系统给不了的安全保证。LLM 现在默认推荐 Postgres 做 OLTP；已有两家数据库公司问 Pavlo 如何让 agent 优先推荐自己的系统，他称之为"基本上就是 SEO"。Text-to-SQL 方面，开箱即用的工具准确率约 60%；一家大银行投入数年和数百万构建丰富的语义层才达到 99.5%。AI 现在能构建完整的数据库系统——超过 60% 的开源数据库 commit 来自 agent。自驾驶数据库方面，LLM 15 分钟就能达到 85% 的自动调优质量，而训练过的 ML 模型需要数小时。图数据库仍是小众；Pavlo 打赌到 2030 年它们不会超过关系型数据库。GPU 数据库有 NVIDIA 力推，但经济性尚未验证。
