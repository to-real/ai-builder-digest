## No Priors — Democratizing Security for the Agentic Web with Cloudflare CTO Dane Knecht

*No Priors*

**Log4j 级别的漏洞现在每周出现，未来 18 个月 50% 以上工程时间将花在安全上，但这是过渡期，AI 最终会扫清大部分漏洞。**

Cloudflare CTO Dane Knecht 描绘了 AI 安全的紧迫现状：过去一年一次的 Log4j 级事件现在每周发生，部分由高中生用 agent（"agent kitties"）发现而非国家级攻击者。他预计未来 18 个月超 50% 工程时间投入安全，但这是短期过渡，AI 最终会审计完大部分代码并找到大部分 bug。关键洞察：AI 当前生成的代码反而更冗余更不安全（"AI is very verbose, it likes to create complexity"），人类判断仍不可替代。Cloudflare 的应对包括内部 Codex 文档定义安全构建原则、agent 在 review 流程中执行、红队从 1 个扩展到 4-5 个。

在 agentic web 经济模型上，Knecht 认为人类和 agent 共用同一套 web 是"messy middle"，agent 一秒读千页但网站按人类 CPM 变现，需要新的微支付基础设施。Cloudflare 已发布内容变现网关（含 agent 钱包和稳定币）和与 OpenAI 合作的 Signals 项目（让 agent 主动发现新内容而非爬取全站）。他还分享了 Cloudflare OS（内部 AI 平台，让非技术团队安全使用 AI）和"千名实习生"策略（AI 原生一代推动组织变革）。

"AI has become the tool that's causing this kind of security apocalypse. It is also the tool that can help us solve it faster as well."
