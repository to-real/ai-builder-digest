## Guillermo Rauch

*CEO, Vercel*

**xeet proves verification engineering is the real AI coding paradigm: an oracle verifies, CI files PRs, agents act.**

Introducing xeet: a hermetic, pixel-perfect X post renderer in safe Rust/wasm that renders a post to PNG in ~1ms with zero browser, network, or filesystem dependencies. It reproduces Blink & HarfBuzz text shaping, 1/64px line breaking, RTL bidi, 28 Chirp font subsets, CJK/Math/Emoji fallbacks, and "Show more" rules. The key innovation is the "autorepo" structure: an oracle boots Chrome to verify tens of thousands of text layout rules, a CI canary watches for changes and files signed PRs for agents to act on. Conceived from the ground up around verification engineering. Also shared that AI models are getting good at naming — a CLI tool named itself 𝚑𝚘𝚐 🐖.

xeet 证明了验证工程才是 AI 编程的真正范式：oracle 验证、CI 提 PR、agent 执行。这个 Rust/wasm 渲染器 1ms 出图，零浏览器依赖，完整复刻 Blink 文本排版。核心创新是 autorepo 架构——oracle 启动 Chrome 验证数万条布局规则，CI 监控变化后自动提 PR 让 agent 处理。Rauch 还发现 AI 起名能力已经很强，一个诊断 CLI 自己取名叫 𝚑𝚘𝚐 🐖。

## Peter Yang

*AI Tutorials & Interviews*

**Claude 的默认设计风格是可破解的：Anthropic 在 design prompt 里直接告诉模型"你倾向于这两种字体和颜色，别用"。**

Nate Parrott at Anthropic explained that when Claude creates something in a fresh context, it invents what it thinks is a brilliant visual style — serif text, off-white background, orange accents, bars on card edges — because it's only ever done this once in its context window, so it thinks it's original. The fix: Anthropic's Claude Design prompt explicitly tells the model "you tend to overly bias toward these two fonts and colors, so don't use them unless the user asks." Also shared that prototyping cycles have compressed from weeks to 1-2 days at Anthropic, but the cycle of putting things in users' hands and validating usage hasn't compressed.

Anthropic 的 Nate Parrott 透露，Claude 在全新上下文里创作时会自以为发明了绝妙视觉风格——衬线字体、米白背景、橙色点缀——因为上下文窗口里它只做过一次，觉得自己很原创。解法：design prompt 里直接写"你倾向于这两种字体和颜色，除非用户要求否则别用"。原型周期从几周压缩到 1-2 天，但用户验证周期没有缩短。
