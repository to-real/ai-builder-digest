## Training Data — Box's Aaron Levie: On Reinventing Yourself in the AI Age and Enterprise Diffusion

*Training Data*

**The applied AI layer will capture trillions in value because the gap between a raw model and a real enterprise workflow is vast, messy, and requires domain expertise that labs have no incentive to build.**

Aaron Levie, founder and CEO of Box, has spent 20 years sitting on hundreds of billions of enterprise files. His core argument: the model-to-workflow bridge involves connecting legacy data systems, managing change processes, handling access controls, and sitting idle during human-in-the-loop delays. No research lab wants to do that work, but every enterprise needs it done. This is why application companies become the new neolabs: they start with the workflow, accumulate domain data and expertise, and eventually peel off use cases into their own models (Box already has "BoxLabs"). The "fox guarding the henhouse" problem further guarantees an independent application layer: you want cost-optimized task routing from a party that doesn't care which model wins, not from the model seller. Token subsidization by labs is temporary; once they go public, gross margin discipline kicks in, and noneconomic actors (Meta, China, NVIDIA) will keep driving token costs down, pushing more value to the application tier.

On diffusion: coding adopted AI instantly because code is pure text utility, engineers fix their own MCP bugs, and data lives in GitHub. Every other form of knowledge work lacks these properties. Enterprise data sits in legacy systems behind access controls that require permission requests. Levie's prediction: "In five years from now, I would bet 90% of all tokens in the enterprise are things that a user never kicked off, and they just see a result." And his conviction: "There is quite literally trillion to trillions up for grab at the applied layer, and the companies that know how to build the teams and get to the enterprise will be the ones that win."

Aaron Levie 是 Box 的创始人兼 CEO，20 年来坐拥数千亿份企业文件。他的核心论点：从模型到工作流之间需要连接遗留数据系统、管理变更流程、处理访问控制、在人机协作的间隙等待——没有哪个研究实验室愿意做这些脏活，但每家企业都需要。这就是为什么应用公司会成为新 neolab：它们从工作流出发，积累领域数据和专业知识，最终剥离出专属模型（Box 已有 "BoxLabs"）。"狐狸守鸡窝"问题进一步保证了独立应用层的存在：你需要一个不关心哪个模型胜出的第三方来做成本最优的任务路由，而不是让卖模型的人来决定。实验室的 token 补贴是暂时的；一旦上市，毛利率纪律就会生效，而非经济参与者（Meta、中国、NVIDIA）会持续压低 token 成本，把更多价值推向应用层。

关于扩散：编程瞬间拥抱 AI，因为代码是纯文本工具，工程师自己修 MCP 的 bug，数据就在 GitHub 里。其他所有知识工作都缺这些条件：企业数据躺在遗留系统里，访问控制需要逐个申请权限。Levie 的预测："五年后，我敢赌企业里 90% 的 token 都不是用户主动触发的，他们只是看到一个结果。"而他的信念："应用层实实在在有万亿甚至数万亿的机会，能组建团队、触达企业的公司才会赢。"
