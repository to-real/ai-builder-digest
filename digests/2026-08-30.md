## Anthropic Engineering: An update on recent Claude Code quality reports

Anthropic investigated reports of degraded Claude Code performance and identified three separate bugs: a change in default reasoning effort (high to medium) that users rejected, a caching optimization bug that incorrectly cleared reasoning history, and a system prompt change to reduce verbosity that hurt coding quality. All issues have been resolved as of April 20 (v2.1.116), and usage limits are being reset for subscribers. The company is implementing stricter testing for system prompt changes and ensuring more staff use the public build to catch issues earlier.

Anthropic 调查了关于 Claude Code 性能下降的报告，发现了三个独立的 bug：一个被用户拒绝的默认推理努力变更（从高到中），一个错误清除推理历史的缓存优化 bug，以及一个损害代码质量的减少冗长度的系统提示词变更。截至 4 月 20 日（v2.1.116），所有问题已解决，并正在为订阅用户重置使用限制。该公司正在实施更严格的系统提示词变更测试，并确保更多员工使用公开版本以尽早发现问题。

## Anthropic Engineering: Scaling Managed Agents: Decoupling the brain from the hands

Anthropic introduced "Managed Agents," a hosted service designed to run long-horizon agents by decoupling the "brain" (Claude and its harness) from the "hands" (sandboxes and tools) and the "session" (event log). This architecture treats components like containers as interchangeable "cattle" rather than fragile "pets," allowing for independent failure and replacement. By separating the harness from the execution environment, they reduced Time-To-First-Token (TTFT) by 60% (p50) and over 90% (p95), while also improving security by ensuring credentials are never reachable from the sandbox.

Anthropic 推出了“Managed Agents”，这是一个旨在运行长周期 agent 的托管服务，通过将“大脑”（Claude 及其 harness）与“双手”（沙箱和工具）及“会话”（事件日志）解耦来实现。这种架构将容器等组件视为可互换的“牲畜”而非脆弱的“宠物”，允许独立故障和替换。通过将 harness 与执行环境分离，他们将首字延迟（TTFT）降低了 60%（p50）和 90% 以上（p95），同时通过确保凭据在沙箱中不可达来提高安全性。
