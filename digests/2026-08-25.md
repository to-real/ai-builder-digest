## Claude Blog: Building intelligent apps for Apple platforms with Claude in the Foundation Models framework

**Apple developers can now seamlessly bridge on-device local models with Claude's cloud power for complex reasoning tasks.**

This allows apps to use fast, local on-device models for simple tasks like summarization, then seamlessly hand off to Claude for complex multi-step reasoning, code generation, and web search, all while maintaining type safety through Swift's `@Generable` annotations.

Claude 发布了一个 Swift 包，使 Apple 开发者能够将 Claude 直接集成到 Foundation Models 框架中。这允许应用程序使用快速的本地设备模型处理摘要等简单任务，然后无缝移交给 Claude 进行复杂的多步推理、代码生成和网络搜索，同时通过 Swift 的 `@Generable` 注解保持类型安全。
