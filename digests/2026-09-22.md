## No Priors — Coinbase's Everything Exchange: Agentic Finance, Stablecoins, and Tokenization with CEO Brian Armstrong

*No Priors*

**Crypto rails are the only payment infrastructure that works for the agentic economy, where 76% of transactions are under 30¢.**

Brian Armstrong, Coinbase CEO and co-founder of longevity startup New Limit, lays out why traditional finance breaks at agent scale: credit card fees have a 30¢ minimum, but 76% of agent ecommerce transactions are under 30¢. These are micro-payments for data scraping, API calls, and agent-to-agent tool use. Coinbase's answer: self-custodial wallets for AI agents with no KYC (agents don't have government IDs), and the X402 protocol — now in the Linux Foundation with Google, Cloudflare, and AWS — for agent-to-agent payments. "We don't want the AIs to be unbanked. If we want to bank the AIs, they deserve financial services as well."

Internally, Coinbase built "Toshi," an agent harness where every repository has a "brain" — incident history, financial controls, A/B tests, PR records. When an agent's code is corrected by a human, the fix flows back into the brain, creating recursive self-improvement. Armstrong now spins up 10 parallel agents to execute feature phases and sends PRs instead of pinging teams on Slack. "It's very addictive."

On New Limit: they've built the leading model for epigenetic reprogramming, successfully reprogrammed human cells in humanized mouse models, and are launching Phase 1 clinical trials next year for alcoholic liver disease — a condition with near-zero treatment options today. The long-term vision is a cocktail of therapies reprogramming different cell types to restore youthful function, attacking the meta-problem of aging rather than individual diseases.

Brian Armstrong，Coinbase CEO 兼长寿公司 New Limit 联合创始人，解释了传统金融在 agent 规模下为何失效：信用卡手续费最低 30 美分，但 76% 的 agent 电商交易低于 30 美分。这些微支付用于数据抓取、API 调用和 agent 间工具调用。Coinbase 的方案：给 AI agent 提供无需 KYC 的自托管钱包（agent 没有政府 ID），以及 X402 协议——现已进入 Linux Foundation，Google、Cloudflare、AWS 共同参与。"我们不想让 AI 没有银行账户。如果要给 AI 开户，它们也值得拥有金融服务。"

Coinbase 内部构建了"Toshi"——一个 agent 框架，每个代码仓库都有一个"大脑"：事故历史、财务控制、A/B 测试、PR 记录。当人类修正 agent 的代码时，修正会回流到大脑中，形成递归自我改进。Armstrong 现在会启动 10 个并行 agent 执行功能阶段，直接发 PR 而不是在 Slack 上找团队。"非常上瘾。"

New Limit 方面：他们构建了表观遗传重编程领域最领先的模型，已在人源化小鼠模型中成功重编程人类细胞，明年将启动酒精性肝病的 I 期临床试验——这种病目前几乎没有治疗选择。长期愿景是一组针对不同细胞类型的疗法鸡尾酒，恢复年轻功能，从衰老这个元问题入手而非逐个攻克疾病。
