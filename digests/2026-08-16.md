### Building intelligent apps for Apple platforms with Claude in the Foundation Models framework

Anthropic released a Swift package to integrate Claude with Apple's Foundation Models framework, allowing developers to hand off tasks from on-device models to Claude for complex reasoning or web access. It supports iOS 27, iPadOS 27, macOS 27, visionOS 27, and watchOS 27, enabling typed Swift values and streaming responses.

Anthropic 发布了一个 Swift 包，将 Claude 集成到 Apple 的 Foundation Models 框架中，允许开发者将任务从端侧模型移交给 Claude 以处理复杂推理或网络访问。它支持 iOS 27、iPadOS 27、macOS 27、visionOS 27 和 watch OS 27，支持类型化的 Swift 值和流式响应。

## The MAD Podcast with Matt Turck — How to Build Long-Horizon AI Agents — Mitch Troyanovsky, Basis

*The MAD Podcast with Matt Turck*

**Building reliable long-horizon agents requires treating context as runtime training data and verifying process, not just outcomes.**

Mitch Troyanovsky, cofounder of Basis, explains that building long-horizon agents requires treating context like runtime training data and designing "behaviors" (markdown specs) that verify process, not just outcomes. He argues that while models will eventually swallow these harnesses, current reliability demands human-validated processes, especially in domains like accounting where "getting it right" isn't enough—you must cite primary sources. "The English is more precious because the English affects the performance. The code does not affect the performance."

构建可靠的长周期 Agent 需要将 context 视为运行时训练数据，并验证过程而不仅仅是结果。Basis 联合创始人 Mitch Troyanovsky 解释说，构建长周期 Agent 需要将 context 视为运行时训练数据，并设计 "behaviors"（markdown 规范）来验证过程，而不仅仅是结果。他认为虽然模型最终会吞噬这些 harness，但目前的可靠性要求经过人工验证的流程，特别是在会计等领域，"做对"是不够的——你必须引用原始来源。"English 更珍贵，因为它影响性能，而代码不影响性能。"
