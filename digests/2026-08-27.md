## Training Data — Parallel's Parag Agrawal: Building a New Web for AI Agents

*Training Data*

**The Takeaway:** The internet is shifting from a human-centric click economy to an agentic web where search volume increases 1000x, requiring new infrastructure and economic models based on value attribution rather than advertising.

**核心观点：** 互联网正从以人类为中心的点击经济转向 agentic web，搜索量将增加 1000 倍，这需要基于价值归因而非广告的新基础设施和经济模式。

Parag Agrawal, former CEO of Twitter and founder of Parallel Web Systems, argues that the traditional search paradigm is broken for AI agents. While humans perform a few dozen searches a day, agents perform thousands, making human click data—a core signal for Google—irrelevant or even a "bug." Parallel is building a search engine specifically for agents, optimizing for the "billion to billion matching problem" of queries to web pages using compressed information and agent feedback loops instead of human ratings.

Twitter 前首席执行官、Parallel Web Systems 创始人 Parag Agrawal 认为，传统的搜索范式对 AI agent 来说是行不通的。人类每天只进行几十次搜索，而 agent 进行数千次，这使得人类点击数据——Google 的核心信号——变得无关紧要，甚至是一个“bug”。Parallel 正在专门为 agent 构建搜索引擎，利用压缩信息和 agent 反馈循环而非人类评分来优化查询到网页的“十亿对十亿匹配问题”。

Agrawal highlights a critical economic shift: the ad-based model fails when agents, not human eyeballs, consume content. He proposes a new economic framework using Shapley values from game theory to determine how much a specific piece of content contributed to an agent's final output. This allows for differential pricing where content owners are paid based on the value their data provided to a high-value task (e.g., a banker's research) versus a low-value one. "Our view at Parallel is that human click data is a bug. An agent doing work with search should rely on agent feedback, not human feedback," Agrawal states. He envisions a future where the web moves from "pull" to "push," where agents subscribe to data streams and execute work proactively based on changes detected across the internet.

Agrawal 强调了一个关键的经济转变：当消费内容的是 agent 而不是人类眼球时，基于广告的模式就会失效。他提出了一种使用博弈论中 Shapley 值的新经济框架，以确定特定内容片段对 agent 最终输出的贡献程度。这允许实行差异化定价，内容所有者根据其数据为高价值任务（例如银行家的研究）与低价值任务提供的价值来获得报酬。“我们在 Parallel 的观点是，人类点击数据是一个 bug。使用搜索进行工作的 agent 应该依赖 agent 反馈，而不是人类反馈，”Agrawal 说。他设想了一个未来，网络从“拉取”转向“推送”，agent 订阅数据流并根据互联网上检测到的变化主动执行工作。
