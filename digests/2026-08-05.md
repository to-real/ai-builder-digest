## Anthropic Engineering: Scaling Managed Agents: Decoupling the brain from the hands

Anthropic introduces Managed Agents, a hosted service designed to decouple the agent "brain" (harness/model) from the "hands" (sandboxes/tools) and the "session" (log). This architecture, inspired by operating systems virtualizing hardware, treats containers as "cattle" rather than "pets," allowing for independent failure recovery and significantly reduced time-to-first-token (TTFT). It enables secure credential handling by keeping tokens out of the sandbox and supports connecting to customer VPCs without network peering.

Anthropic 推出了 Managed Agents，这是一项旨在将 Agent 的“大脑”（harness/模型）与“手”（沙箱/工具）和“会话”（日志）解耦的托管服务。这种架构受操作系统虚拟化硬件的启发，将容器视为“牲畜”而非“宠物”，允许独立的故障恢复并显著减少首字延迟（TTFT）。它通过将凭证保留在沙箱之外来实现安全的凭证处理，并支持无需网络对等即可连接到客户的 VPC。
