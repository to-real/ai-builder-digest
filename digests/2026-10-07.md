## Guillermo Rauch

*CEO, Vercel*

**gdp-ts brings compile-time security proofs to TypeScript — exactly the safety layer AI-generated code needs.**

Rauch introduces gdp-ts (Ghosts of Departed Proofs for TypeScript): a library, linter, and AI skill that requires callers to supply "proofs" they performed authorization checks before accessing sensitive functions. The typechecker enforces this at compile time. The inversion: human code review can't keep up with agent-written code, but agents *thrive* on tight constraints that would frustrate humans — same dynamic driving Rust's borrow checker adoption. The README models a real Vercel API constraint: changing a project password requires proof of a specific role + entitlement.

Rauch 发布 gdp-ts（Ghosts of Departed Proofs for TypeScript）：一个库、linter 和 AI skill，要求调用方在访问敏感函数前提供已执行授权检查的"证明"，类型检查器在编译时强制执行。逻辑反转：人类代码审查跟不上 agent 写代码的速度，但 agent 恰恰在人类会觉得沮丧的硬约束下如鱼得水——这和 Rust borrow checker 的崛起是同一股力量。README 用 Vercel 真实 API 约束建模：修改项目密码需要特定角色 + 权限的证明。

## Thariq

*Claude Code, Anthropic*

**Structured planning beats raw HTML generation for token efficiency — and "local hands" lets cloud Claude touch your local files.**

Thariq shares that planning with structured representations (state machines, diagrams, code snippets) is far more token-efficient than having the model regenerate HTML from scratch each time. ## Garry Tan

*President & CEO, Y Combinator*

**Lab harnesses burn tokens by design; startup harnesses win by swapping that burn for deterministic, tested code.**

Tan argues that harnesses from labs have a structural incentive to maximize token consumption, whereas startup-built harnesses (like Grep) can automatically convert token burn into deterministic, repeatable, tested code just by observing agent usage. Tan 指出，实验室出品的 harness 在结构上有最大化 token 消耗的激励，而创业公司做的 harness（如 Grep）能通过观察 agent 使用自动把 token 燃烧转化为确定性、可重复、可测试的代码。另外，他认为 Halmos 正在为即将到来的 AGI Science Loops 构建 "Muse/Instinct" 层。
